Alt codes explained

Most Hindi letters on the Kruti Dev layout have their own key. A few do not. For those, typists use an Alt code: hold the Alt key, type a number on the numeric keypad, and let go. The number picks a character of the Kruti Dev font. This page explains which characters need it and how Tankan treats them.

How to type an Alt code on Windows

Turn on Num Lock. Hold down the left Alt key. While holding it, type the four digits on the numeric keypad on the right of the keyboard (not the number row above the letters), for example 0 1 6 1. Release Alt and the character appears. Many laptops have no separate numeric keypad, which makes Alt codes hard or impossible there. Some laptops use a hidden keypad under an Fn key. Check your laptop's manual.

Which characters need Alt codes

These are some examples taken from the lessons in Tankan:

  • Alt+0161: chandrabindu (ँ)
  • Alt+0197: ऊ (long oo vowel)
  • Alt+0183: avagraha (ऽ)
  • Alt+0182: half फ (फ्)
  • Alt+0221: फ्र
  • Alt+0235: ह्र

These characters are rare in everyday words, but they appear in some words, so a complete typist should know they exist. Many other conjuncts, such as क्त, ट्ट and ड्ड, do not need Alt codes in Tankan. They are typed with regular keys, for example क्त is Shift+d then r, and ट्ट is Shift+v, the virama key (Shift+`) and Shift+v again. The on-screen hint always shows the exact keys.

How Tankan handles them

Tankan does not teach Alt codes as separate lessons. Key unlocking uses only the 54 characters that regular keys can type. Words that need an Alt code do not appear in guided lessons. They can appear in Books, Essays, Official words and Custom text, and when they do, the hint strip shows the Alt code to press. You never have to memorise them in advance.

The "No Alt codes" option

Under Lessons, Typing options, Tankan has a switch called No Alt codes (approximate forms). It is off by default. When you turn it on, any character that needs an Alt code is replaced by the closest form that regular keys can type. For example the chandrabindu is typed as a (the anusvara), and a few others are replaced by two plain keys. This is handy if your keyboard has no numeric keypad and you only want practice. It is not correct spelling, so do not use it if you are preparing for a test that needs exact characters.

Are Alt codes still needed?

If you type Unicode Hindi (for example with the Windows Hindi keyboard or Google input tools), you do not need Alt codes at all. They belong to the older Kruti Dev font system, which many government offices and typing tests still use. If your work is on Kruti Dev, it is worth learning the few codes that matter for your documents.

ऑल्ट कोड समझें

कृतिदेव लेआउट पर ज़्यादातर हिंदी अक्षरों की अपनी चाबी है। कुछ की नहीं है। उनके लिए टाइपिस्ट ऑल्ट कोड इस्तेमाल करते हैं: Alt चाबी दबाए रखें, न्यूमेरिक कीपैड पर एक संख्या टाइप करें और छोड़ दें। संख्या कृतिदेव फ़ॉन्ट का एक अक्षर चुनती है। यह पन्ना बताता है कि किन अक्षरों के लिए यह चाहिए और टंकण उनके साथ क्या करता है।

विंडोज़ पर ऑल्ट कोड कैसे टाइप करें

Num Lock चालू करें। बायाँ Alt दबाए रखें। उसे दबाए रखते हुए कीबोर्ड के दाईं ओर के न्यूमेरिक कीपैड पर चार अंक टाइप करें (अक्षरों के ऊपर वाली संख्या पंक्ति पर नहीं), जैसे 0 1 6 1। Alt छोड़ें, अक्षर आ जाएगा। कई लैपटॉप में अलग न्यूमेरिक कीपैड नहीं होता, तब ऑल्ट कोड कठिन या असंभव होते हैं। कुछ लैपटॉप में Fn चाबी के नीचे छिपा कीपैड होता है। अपने लैपटॉप की पुस्तिका देखें।

किन अक्षरों के लिए ऑल्ट कोड चाहिए

टंकण के पाठों से कुछ उदाहरण:

  • Alt+0161: चंद्रबिंदु (ँ)
  • Alt+0197: ऊ (दीर्घ ऊ स्वर)
  • Alt+0183: अवग्रह (ऽ)
  • Alt+0182: आधा फ (फ्)
  • Alt+0221: फ्र
  • Alt+0235: ह्र

ये अक्षर रोज़ के शब्दों में कम आते हैं, पर कुछ शब्दों में आते हैं, इसलिए पूरे टाइपिस्ट को इनका पता होना चाहिए। क्त, ट्ट और ड्ड जैसे कई दूसरे संयुक्ताक्षरों के लिए टंकण में ऑल्ट कोड नहीं चाहिए। वे सामान्य चाबियों से टाइप होते हैं, जैसे क्त Shift+d फिर r से। स्क्रीन पर संकेत हमेशा ठीक चाबियाँ दिखाता है।

टंकण इन्हें कैसे सँभालता है

टंकण ऑल्ट कोड को अलग पाठों में नहीं सिखाता। चाबियाँ खुलने का क्रम सिर्फ़ उन 54 अक्षरों पर चलता है जो सामान्य चाबियों से टाइप होते हैं। जिन शब्दों में ऑल्ट कोड लगता है, वे निर्देशित पाठों में नहीं आते। वे Books, Essays, Official words और Custom text में आ सकते हैं, और तब संकेत-पट्टी दबाने वाला ऑल्ट कोड दिखाती है। उन्हें पहले से याद करना ज़रूरी नहीं।

"No Alt codes" विकल्प

Lessons में, Typing options के अंतर्गत, टंकण में No Alt codes (approximate forms) नाम का स्विच है। यह शुरू में बंद रहता है। इसे चालू करने पर, जिस अक्षर के लिए ऑल्ट कोड चाहिए उसकी जगह सामान्य चाबियों से बनने वाला सबसे नज़दीकी रूप आ जाता है। जैसे चंद्रबिंदु की जगह a (अनुस्वार) टाइप होता है, और कुछ और की जगह दो सादी चाबियाँ। यह तब काम का है जब आपके कीबोर्ड पर न्यूमेरिक कीपैड नहीं है और आपको सिर्फ़ अभ्यास करना है। यह सही वर्तनी नहीं है, इसलिए ऐसी परीक्षा की तैयारी में इसे न चलाएँ जिसमें सटीक अक्षर चाहिए।

क्या ऑल्ट कोड अब भी ज़रूरी हैं?

यूनिकोड हिंदी टाइप करते हों (जैसे विंडोज़ के हिंदी कीबोर्ड या Google इनपुट टूल से), तो ऑल्ट कोड बिल्कुल नहीं चाहिए। वे पुराने कृतिदेव फ़ॉन्ट प्रणाली के हैं, जो कई सरकारी दफ़्तरों और टाइपिंग परीक्षाओं में अब भी चलती है। आपका काम कृतिदेव पर है, तो अपने दस्तावेज़ों के लिए ज़रूरी कुछ कोड सीख लेना अच्छा है।
